# 視力保健大作戰

以成福國小 112 學年度健康促進計畫中的「主議題（視力保健）六大範疇 SWOT 分析」為內容，設計給教師共學使用的互動配對遊戲。

## 遊戲特色

- 8 張較難判斷、可跨校使用的 SWOT 敘述卡
- 六大範疇可愛校園地圖
- 手機採點選操作，桌機支援點選與拖曳
- 答錯提供提示、答對呈現判斷規則
- 不計時，重視理解與回顧
- 桌機與手機皆可使用

## 使用方式

直接開啟 `index.html`，不需安裝任何套件。

## 教學內容來源

《新北市成福國小 112 學年度學校健康促進申請計畫書（審核通過版）》第 7–10 頁，主議題「視力保健」六大範疇 SWOT 分析。
